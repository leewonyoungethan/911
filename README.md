# 맑은 하늘 (Clear Skies)

2001년 9월 11일 아침의 납치를 막아내는 가상의 3단계 브라우저 게임입니다.
빌드 과정 없이 `index.html` 하나로 동작합니다. 파일을 브라우저로 열거나 GitHub Pages로 배포하세요.

## 진행

1. **공항 보안검색대**: 벨트 위로 쏟아지는 가방의 X선 화면에서 커터칼·단검·면도칼을 직접 탭해 빼냅니다. 금색 ★ 가방엔 흉기가 여러 개.
2. **관제 레이더**: 놓친 흉기가 있으면 그 항공편이 이상 신호(주황 링)를 보냅니다. 링이 줄어들기 전에 탭해 경보를 보내세요.
3. **기내**: 경보가 늦은 항공편에서는 보안요원이 되어 납치범에게 부딪히거나 돌진해 조종실 문을 지킵니다.

## 조작

| 단계 | 조작 |
|---|---|
| 1 | 흉기를 탭/클릭 |
| 2 | 이상 신호 항공기를 탭/클릭 |
| 3 | 끌기 또는 WASD·방향키 이동 · 두 번 탭/Space 돌진 · E 승객 돌격 |

결과 화면에 S~D 등급과 최고 기록이 표시됩니다.

---

실제 2001년 9월 11일에는 네 대의 항공기가 납치되어 2,977명이 목숨을 잃었습니다.
이 게임은 그날의 희생자와 구조에 나선 모든 이들을 기억하기 위한 가상의 이야기입니다.
